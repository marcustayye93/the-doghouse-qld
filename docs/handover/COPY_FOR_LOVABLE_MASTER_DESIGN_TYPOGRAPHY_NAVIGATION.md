THE DOGHOUSE QLD
MASTER DESIGN, TYPOGRAPHY AND NAVIGATION CHANGES
These instructions update and override any earlier build instructions where there is a conflict. Apply these rules consistently across the entire website.
1. HOMEPAGE HEADER AND LOGO
At the very top of the homepage, display The Doghouse QLD logo centred horizontally.
The logo should be fairly large and visually prominent. It should clearly establish The Doghouse QLD brand when a visitor first arrives at the website.
Maintain generous white space around the logo.
The primary website background remains white.
Do not make the logo so small that it resembles a standard compact navigation logo.

2. HOMEPAGE MAIN NAVIGATION
Directly underneath the large centred logo, create the main desktop navigation.
The navigation must sit between two thin horizontal lines:
One thin horizontal line immediately above the menu 
One thin horizontal line immediately below the menu 
Both horizontal lines must use the approved warm tan-chocolate brown.
The navigation text must also use this same warm tan-chocolate brown.
The colour should:
Be noticeably softer and warmer than dark chocolate brown 
Have a tan influence 
Remain sufficiently dark to be clearly readable against white 
Be used consistently throughout the website 
Display the main navigation horizontally:
HOME | ABOUT US | PUPPIES | OUR DOGS | CAVOODLES | TRAINING | DOGHOUSE DELI | RESOURCES
Use Aptos for the navigation text.
Keep the navigation elegant, clean and uncluttered.

3. HOMEPAGE IMAGE GALLERY
Directly beneath the navigation area, create a prominent photographic gallery.
The gallery consists of:
16 photographs in total, displayed as four sets of four photographs.
On desktop, show four photographs simultaneously.
Each photograph must:
Be square, 1:1 
Have slightly rounded corners 
Be equal in size 
Have consistent spacing 
Use genuine Doghouse QLD supplied imagery 
Remain large enough to be visually striking 
Gallery movement
The first four photographs appear together.
After an appropriate viewing period, the complete group of four should slide smoothly towards the left, revealing the next group of four photographs.
Sequence:
Images 1-4 → Images 5-8 → Images 9-12 → Images 13-16
After the fourth set has been displayed, allow the carousel to cycle naturally back to the beginning.
The transition should be smooth, polished and gentle.
Do not use:
Abrupt image changes 
Flashing transitions 
Excessively fast movement 
Dramatic zoom effects 
Individual photographs moving at unrelated times 
The four photographs should visually behave as one coordinated group.
Allow visitors enough time to comfortably view each set before the next set appears.
The gallery must be fully responsive on tablet and mobile.
Do not force four tiny photographs side by side on mobile. Adapt the number of photographs visible at once appropriately while retaining access to all 16 photographs and maintaining the sliding-gallery experience.
Respect reduced-motion accessibility preferences by providing an appropriate reduced-motion or static alternative.

4. HOMEPAGE APPLY NOW CTA
Directly following the homepage photographic gallery, provide appropriate breathing space and display the standard Doghouse QLD:
Apply Now
button.
Use the approved rounded rectangular Apply Now button style.
Use Aptos for the Apply Now text.
The words Apply Now appear in white.
Paw-print animation
Include two small white paw prints as part of the Apply Now button animation.
The paw prints should initially be invisible.
Then:
The first white paw print gently appears. 
The second white paw print follows shortly afterwards. 
The effect should resemble a little dog taking two steps onto the button. 
After a short pause, the paw prints gently disappear. 
Repeat the animation periodically. 
Use a subtle fade combined with a small stepping movement.
The animation should attract the visitor's eye without appearing childish, busy or distracting.
A gentle cycle approximately every 4 to 6 seconds is appropriate.
Create this as one reusable global Apply Now component so the same button style and paw-print behaviour appears consistently wherever the standard Apply Now CTA is used throughout the website.
Respect reduced-motion accessibility preferences. When reduced motion is requested, display the button without the paw animation.

5. HOMEPAGE TEXT UNDER APPLY NOW
Directly underneath the Apply Now button display this exact sentence:
Start your journey to welcome a Doghouse Cavoodle puppy into your home.
Use Aptos.
Use the approved warm tan-chocolate brown.
The sentence should visually support the Apply Now CTA without competing with it.

Major headings
Use:
Corinthia Bold

Bright teal matching the teal in The Doghouse QLD logo
All general website typography
Use:
Aptos

Body copy 
Paragraphs 
Navigation 
Dropdown navigation 
Subheadings 
Buttons 
Form labels 
Form fields where appropriate 
Related-page navigation 
Footer text 
General informational text 
Captions and supporting copy where appropriate 
Do not substitute another body font unless specifically instructed by The Doghouse QLD.

7. MAJOR PAGE HEADINGS
Major page headings must use:
Corinthia Bold
Colour:
Bright teal matching The Doghouse QLD logo
This treatment is reserved for the principal page heading and other specifically approved major headings.
Do not automatically apply Corinthia Bold to every heading on the page.
Do not use Corinthia Bold for ordinary content subheadings.
Do not use tan-chocolate brown for the principal page heading.
The visual distinction between the main page heading and the rest of the page hierarchy should be immediately apparent.

8. SUBHEADINGS
All ordinary content subheadings must use:
Aptos Bold or an appropriate Aptos semi-bold weight
Colour:
Warm tan-chocolate brown
Subheadings should:
Be larger than the surrounding body copy 
Be clearly distinguishable from body paragraphs 
Remain clean and highly readable 
Have appropriate spacing above and below 
Remain subordinate to the main Corinthia Bold teal page heading 
Do not use Corinthia Bold for ordinary subheadings.
Do not use bright teal for ordinary subheadings.

9. BODY COPY
All general body copy must use:
Aptos
Colour:
Warm tan-chocolate brown
The brown should:
Be warm 
Have a noticeable tan influence 
Not appear as dark chocolate brown 
Remain sufficiently dark to provide excellent readability against white 
Maintain comfortable:
Font size 
Line height 
Paragraph spacing 
Reading width 
The Doghouse QLD website contains substantial educational information, so readability is extremely important.
Do not use excessively small or tightly spaced body text.

11. DESKTOP DROPDOWN MENU BEHAVIOUR
Correct the current desktop dropdown-menu behaviour.
When a visitor selects a main navigation category such as:
ABOUT US
the relevant submenu may open.
However, when the visitor selects one of the submenu destinations, the dropdown must:
AUTOMATICALLY CLOSE IMMEDIATELY AFTER THE SELECTION.
The visitor must not have to click somewhere else on the page to make the dropdown disappear.
Required behaviour:
Main navigation selected → submenu opens → visitor selects subpage → destination opens → dropdown closes automatically.
The dropdown must not remain floating over the destination page.
Also close the dropdown appropriately when:
Another main navigation category is selected 
The visitor clicks outside the navigation 
Escape is pressed where appropriate for accessibility 
Use Aptos for all dropdown-menu text.

12. MOBILE NAVIGATION
Apply the same underlying principle to mobile navigation.
When a visitor selects a destination from an expanded mobile submenu:
Navigate to the selected destination 
Automatically close the submenu/navigation appropriately 
Reveal the selected page clearly 
Do not leave an unnecessary navigation overlay covering the destination content 
Mobile navigation must remain touch-friendly and accessible.
Use Aptos for mobile navigation text.

13. REMOVE SUBPAGE CARD GRIDS FROM MAIN SECTION PAGES
The current design in which selecting a main navigation heading produces a page containing multiple squares or cards with the names of its subsections is not approved.
Remove this treatment.
For example, do not create a grid of large cards labelled:
Our Story 
Meet the Team 
Our Breeding Philosophy 
Health & Health Testing 
Guardian Homes 
simply because these destinations sit beneath ABOUT US.
Apply the same principle to other main navigation categories.
The dropdown navigation already provides access to those destinations.
Do not duplicate the dropdown menu as a large grid of subsection cards on the landing page.

14. MAIN SECTION LANDING PAGE IMAGE TREATMENT
Where a main navigation category has a general landing page, replace the subsection-card/grid treatment with a beautiful general Doghouse QLD photograph appropriate to that section.
For these general landing-page photographs, do not force the photograph into the standard square image treatment used beside substantive content elsewhere on the website.
Instead, allow the photograph to sit naturally within the page and gently blend into the overall page design.
The image treatment should feel:
Soft 
Natural 
Elegant 
Integrated 
Open 
Unboxed 
Do not place these photographs inside:
Heavy cards 
Obvious square frames 
Thick borders 
Visually intrusive containers 
Use genuine Doghouse QLD supplied imagery only.

15. MAIN SECTION NAVIGATION EXPERIENCE
The intended desktop navigation experience is:
Visitor sees the clean main navigation between the two thin tan-chocolate horizontal lines. 
Visitor selects or hovers over a main category where appropriate. 
Its submenu appears. 
Visitor selects the desired subpage. 
The submenu automatically disappears. 
The selected page becomes the clear visual focus. 
Do not leave the dropdown floating over the selected page.
Do not simultaneously display a redundant grid of the same submenu destinations on the landing page.

16. RELATED-PAGE NAVIGATION
The removal of subsection-card grids from main landing pages does not remove the previously approved related-page navigation near the bottom of appropriate individual content pages.
These are two different elements.
Remove the large redundant landing-page card grids.
Retain the approved understated related-section navigation near the bottom of individual pages where specified.
Use Aptos for related-page navigation.

17. APPLY NOW BUTTONS THROUGHOUT THE WEBSITE
All standard Apply Now buttons across the website must use the same reusable global component.
They must consistently include:
Rounded rectangular shape 
Approved button background 
White Aptos text 
Two small animated white paw prints 
Sequential paw-print appearance 
Gentle stepping/fade effect 
Approximately 4 to 6 second repeat cycle 
Appropriate hover/tap response 
Appropriate reduced-motion accessibility support 
Do not manually create different Apply Now buttons on individual pages.
Changes to the reusable component should automatically update all standard Apply Now buttons throughout the website.

18. GENERAL BUTTON TYPOGRAPHY
Use Aptos for standard website buttons and controls.

Do not use Corinthia Bold for functional buttons.

Apply Now

19. READ MORE AND READ LESS
Where page-specific instructions require progressive disclosure:
Read more... must remain directly underneath the final sentence of the approved opening copy.
When expanded, the complete extended content appears on the same page.
Read less must appear directly underneath the final sentence of the extended content.
Use Aptos for both controls.
Do not move these controls away from the text they belong to simply to accommodate nearby photographs or layout components.

20. FOOTER TYPOGRAPHY

Ensure sufficient colour contrast between footer text and the pale teal background.
The footer should feel visually distinct from the white body of the website while remaining part of the same design system.
